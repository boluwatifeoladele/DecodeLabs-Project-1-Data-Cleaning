# DecodeLabs Project 1: Data Cleaning and Preparation Using Excel

## Project Overview
This project focused on cleaning and preparing a dataset for analysis using Microsoft Excel. The goal was to improve data quality, maintain consistency, and ensure the dataset was properly organised for further analysis.

## Tools Used
- Microsoft Excel

## Data Cleaning Activities
- Checked for missing values and reviewed data completeness.
- Checked for duplicate records and identifiers.
- Standardised date and number formats.
- Reviewed formulas and calculations for accuracy.
- Performed data quality checks to identify inconsistencies.
- Organised the cleaned dataset for further analysis.

## Project Deliverables
The Excel workbook contains the cleaned dataset and supporting work completed during the data preparation process.

**File:** `DecodeLabs_Project1_Cleaned data.xlsx`

## Key Learning Outcomes
This project provided practical experience in data preparation, data quality assessment, spreadsheet organisation, and the use of Excel to prepare data for analysis.

## Conclusion
Data cleaning is an important stage of the data analysis process because accurate, consistent, and well-organised data supports more reliable analysis and interpretation.
